# 念念智剪设计记忆

## 产品与受众

念念智剪是共用 AI 视频剪辑能力，会接入两个上层宿主：

- 念念 AI：AI 转绘和 AI 短剧用户，需要把转绘素材、短剧片段、角色画面、图生视频和剧情内容整理成可发布视频。
- 念念智选：电商带货用户，需要把商品素材、探店开箱、测评口播和卖点讲解整理成可发布视频。

普通用户首先需要选择“我要做哪种视频”，而不是理解剪辑软件、Agent、模型或时间线。高级用户和运营人员再进入专业模式做精修。

## Design Read

这是一个嵌入念念 AI 画布和念念智选工作台的视频创作入口，视觉语言应是“创作工作台”：专业、清楚、有视频行业质感，但不做泛 AI 紫蓝渐变聊天页，也不做模板市场式堆卡片。

## 三个设计参数

- 变化度：5。保持清晰、稳定、可信。
- 动效强度：3。动效只用于方案选择、生成进度、预览状态和轻量反馈。
- 信息密度：6。允许比消费级工具更密，但每屏只服务一个用户决策。

## 快速模式首页原则

- 第一屏问“你想做哪种视频？”。
- 用户可见名称使用“成片方案”“视频类型”“发布场景”或“创作目标”，不用“模板”作为主文案。
- 每张方案卡必须说明结果、适用场景、素材要求、预计结果和下一步动作。
- 卡片之间要有信息重心差异，不要做四张同质化功能卡。
- 不在快速模式首屏暴露 API、模型、供应商、Agent 工具名、时间线轨道或导出参数。

## 宿主差异

念念 AI 的快速方案优先级：

1. 短剧片段精修。
2. 剧情混剪发布版。
3. 转绘素材成片。
4. 图生视频整理。

念念智选的快速方案优先级：

1. 商品种草短视频。
2. 测评口播发布版。
3. 探店开箱发布版。
4. 卖点讲解视频。

共用方案：

- 无声素材解说视频。
- 口播精剪发布版。
- 图文素材成片。
- 平台发布版包装。

## 专业模式原则

专业模式保留完整念念智剪编辑器。快速模式生成的所有结果都必须能在专业模式继续修改，包括片段、字幕、旁白、BGM、标题包装、转场和导出规格。

## 反模式

- 不把快速模式做成不可编辑的视频生成器。
- 不用“很多模板”代替清晰的成片方案。
- 不把电商带货默认当成念念 AI 的主业务。
- 不让普通用户看到 API 配置、模型路由和供应商细节。
- 不用泛 AI 紫蓝渐变、玻璃卡片和空泛宣传文案掩盖真实工作流。
