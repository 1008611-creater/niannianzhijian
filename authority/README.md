## Evidence rule

An item is `confirmed` only when this repository, a dated read-only browser
readback, or a preserved screenshot proves it. Missing historical files and
unread approved screenshots remain `pending-verification`; they must not be
recreated from memory or inferred from a candidate image.

## Current release boundary

The local source is the only implementation input for this phase. Online parity
is not claimed, deployment is not authorized, and no release candidate may be
assembled from an archive or an old canvas family.
