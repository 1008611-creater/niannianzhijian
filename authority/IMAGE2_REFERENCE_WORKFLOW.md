# Image2 真实页面参考工作流

本项目的 Image2 页面重绘必须以当前已实现的念念 AI 页面截图为输入，目标是
在保留真实结构、品牌、文案和可见控件的前提下提升视觉质量。不得使用自拟
页面、空白线框或未经实现的理想图作为唯一 reference。

## Reference 优先级

1. 当前念念 AI 真实页面的干净浏览器截图；
2. 当前仓库中已确认的品牌和素材资源；
3. `docs/frontend-targets/` 目标图，仅用于比较层级和验收方向，不得作为真实
   页面事实来源。

## 当前已采集来源

本轮从 `https://ai.cauai.fun/` 及其公开页面采集了首页、项目管理、工作台、
导演台、Studio 项目库和 Studio 画布的现场截图。截图含运行态的部分只保存在
本机临时 reference 目录，不进入源码、文档或 Git；需要时重新从线上当前页面
采集，避免把项目数据固化进权威资料。

## 每张图的执行合同

- 先记录真实来源 URL、采集时间、视口和页面状态。
- 用对应真实截图作为 Image2 reference，再使用页面专属 prompt 做保真重绘。
- 生成结果必须单独存放，不能覆盖真实页面截图或现有目标图。
- 只有在输出存在、签名正确、尺寸符合渠道限制且人工确认仍保留真实页面
  结构后，才可进入目标图更新；失败或超时只记录结果，不伪造图片。
- `yunfei-1k` 只允许 `gpt-image-2 + 1024x1024`，只能做方图实验，不能替代
  2048x1152 桌面目标。

## 当前暂停条件

若当前页面截图无法访问、页面不是念念真实实现、或渠道不支持所需尺寸，停止
该页重绘并报告缺失证据；不得自行设计替代页面。
