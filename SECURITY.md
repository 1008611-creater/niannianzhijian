# Security Policy

Do not report credentials, cookies, signed URLs, user media, or exploitable
details in a public Issue or Pull Request.

Use GitHub's private vulnerability reporting page when it is available for this
private repository: <https://github.com/1008611-creater/niannian-ai/security/advisories/new>.
If that page is unavailable, contact the repository owner privately through
GitHub before disclosing details.

Provider keys remain server-only in the system environment file. A key pasted
into chat, an Issue, a PR, a log, or a release must be treated as exposed and
rotated at its Provider before continuing.
