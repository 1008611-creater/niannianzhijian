# 念念 AI 原站继承矩阵

审计日期：2026-08-10

## 目的

本文件先回答“原站已经有什么，哪些必须继承”，再允许目标图和生产代码提出改造。任何目标图若遗漏本矩阵中的受保护项，不具备前端权威性。

## 原站证据范围

已在真实线上页面检查以下表面：

- `/`：电影感首页与全局导航。
- `/#projects`：主站项目管理。
- `/#workbench`：创作方式工作台。
- `/studio/#/studio`：Studio 项目库。
- `/studio/?step=generate#/studio?...`：当前念念画布、生成区与项目资源管理器。
- `/#director-desk`：3D 导演台。

只观察页面可见结构、文案和交互，不读取 Cookie、密钥、浏览器存储或私有响应。含用户运行数据的页面只用于现场审计，不保存截图或数据到 Git。

## 继承等级

- **A 原样继承**：品牌、结构或业务行为已经确认，不因新目标图改变。
- **B 结构继承后优化**：保留位置、心智模型和数据合同，可改善层级、状态和响应式。
- **C 保留入口但标明能力状态**：现有入口不能消失；若服务端尚不可执行，显示“仅编辑/参考”或明确阻塞。
- **D 另案批准后才可移除**：存在冲突或历史命名，但不能在普通前端改造中顺手删除。

## 原目标图的纠正结论

上一版目标图存在四个错误，现已撤销其权威地位：

1. 把主站项目管理、工作台和 Studio 项目库合并成一个新深色侧栏页面。
2. 把四入口工作台错误缩减为三个入口，遗漏智能剪辑。
3. 把现有浅色 Studio 画布替换成另一套深色画布壳，遗漏三模式、四类资源、八类节点、时间轴与 AI 侧栏。
4. 没有为 3D 导演台建立目标图和逐项继承合同。

修订后的目标图必须先通过本矩阵逐项对照，再能进入实现阶段。
