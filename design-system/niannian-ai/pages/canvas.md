# Canvas Surface Contract

**Mode:** Operate  
**Purpose:** 在当前项目内组织素材、镜头与生成任务。  
**Primary action:** 选择一个已准备好的节点并推进真实项目任务。

## Structure

- 正式入口仅为 `/studio/#/studio?projectId={projectId}`；旧 `#canvas` 只做兼容跳转。
- 先显示当前项目身份、退出/返回和保存状态，再显示画布、检查器与必要工具。
- 节点最小集合：提示词、项目素材、Image2 图像生成、H3 视频生成、导演计划、结果资产。
- 节点之间的边表达依赖、引用、派生、已批准和版本关系；不暴露 Provider 图或内部工作流节点。

## Data and States

- 画布文档只保存 `projectId`、资产 ID、任务 ID、节点位置、边、视口和业务状态。
- 服务端画布文档及 revision 是正式来源；本地缓存只在网络异常时辅助恢复。
- 项目不存在、无权限、保存冲突、上传失败、任务处理中、产物不可读均需独立的可恢复状态。
- stale revision 返回 `CANVAS_REVISION_CONFLICT` 时，明确要求重新读取服务器版本，禁止静默覆盖。

## Visual constraints

- 画布不是仪表盘、表单堆或营销页。节点是唯一需要边框的高频工作单元，页面区域不再嵌套装饰卡片。
- 任务状态通过短透明度或位移过渡呈现，尊重减少动态效果；不能因动画遮挡连线、错误或退出入口。
- 桌面和 `390px` 都必须保留项目退出、保存错误和当前生成确认入口。

## Acceptance

- 有效深链自动打开正确项目；刷新和清空 `localStorage` 后仍恢复服务端项目。
- 新增节点、边、位置与视口后刷新仍存在；跨项目访问被拒绝。
- 生成节点只提交念念服务端任务，真实产物以项目资产 ID 回到节点和交付页。
